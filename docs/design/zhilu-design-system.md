# 职路用户端设计规格

本规格以 `zhilu-dashboard-desktop.png` 与 `zhilu-dashboard-mobile.png` 为实现基准。产品界面服务求职者；现有信息源、运行中心、去重和模型配置继续属于运营后台。

## 视觉方向与色彩锁定

- 背景必须为真白 `#FFFFFF`，不可改成米白或暖灰。
- 主文字为深海军蓝 `#0B1633`，次级文字 `#667085`。
- 主操作使用钴蓝 `#075FF7`，悬停 `#004ED6`，浅选中底 `#EEF5FF`。
- 成功与高匹配使用翠绿 `#0AAE78`，浅底 `#EAF9F3`。
- 分隔线 `#DDE3EC`，弱表面 `#F7F9FC`，不使用紫色渐变、发光或重阴影。
- 阴影只用于移动端固定导航和浮层，普通列表依靠留白与细分隔线组织。

## 字体系统

- 字体栈：`Inter, "PingFang SC", "Microsoft YaHei", system-ui, sans-serif`。
- 桌面主标题 36/44、700；区块标题 20/28、700；正文 15/24、400；控件 14/20、600；表格辅助信息 12/18。
- 移动主标题使用 `clamp(28px, 8vw, 38px)`，行高 1.18；区块标题 24/32；岗位名称 17/24；正文 14/22。
- 所有按钮、输入、底部导航和表格均显式声明字号、字重与行高，不依赖浏览器默认值。

## 容器与响应式

- `>=1200px`：196px 左侧导航，84px 顶栏，主区为推荐内容与约 320px 右侧行动栏；岗位保持表格/列表形态。
- `768-1199px`：导航收窄为图标栏，右栏进入主内容流。
- `<768px`：不显示侧栏，使用固定五项底部导航；内容从 360px 起不出现横向滚动。
- 页面高度使用 `100dvh` 并提供 `100vh` 回退。移动顶栏、底栏和浮层使用 `env(safe-area-inset-*)`。
- 可点击区域不小于 44x44px；输入框移动端不小于 16px 字号，避免 iOS 自动缩放。

## 组件族

- `AppShell`：桌面侧栏、桌面顶栏、移动顶栏、移动底栏四种明确变体。
- `PrimaryButton` / `TextButton` / `IconButton`：统一蓝色、焦点环、禁用与加载状态。
- `ActionRail`：三项今日行动，以开放横向分栏表达，移动端聚合为一个首要行动。
- `JobList` / `JobRow`：桌面为列对齐列表，移动端为无外框行；展示公司/岗位、地点、薪资、匹配度、截止日期及一个主动作。
- `SalaryTarget`：显示用户期望区间、已知岗位薪资位置与未知数据说明；不把未知薪资当作零。
- `PrepNext`：今日题单、完成进度与开始练习动作。
- `AuthPanel`、`ProfileForm`、`PlanComparison`、`QuestionRunner`：沿用同一字体、边框、按钮和列表语言，不新增另一套视觉体系。
- 仅表单、认证、移动主行动和右侧工具区允许有目的的圆角边框；禁止把所有内容包装成卡片网格。

## 图标清单

- 导航：首页、搜索、进度勾选、书本、薪资圆币、用户。
- 顶栏：通知、用户头像/菜单。
- 动作：文档画像、纸飞机投递、日历面试、右向箭头、收藏。
- 图标统一使用 1.8-2px 圆角描边、`currentColor`、20-24px 视觉尺寸；选中导航可使用实心首页图标。右向箭头必须是 SVG，不使用文本字符。

## 首屏允许文案

桌面首屏：`职路`、`今日`、`找岗位`、`求职进度`、`备考中心`、`薪酬洞察`、`我的`、`搜索公司、岗位或城市`、`找到更适合你的下一份工作`、`完善求职画像`、`今日行动`、`为你推荐`、`薪资目标`、`今日练习`、`开始练习`、`查看岗位`。

移动首屏：`职路`、`早上好，林同学`、`今天，向理想工作更近一步`、`完善求职画像`、`继续完善`、`为你推荐`、`即将截止`、`今日练习`、`5 题 · 约 8 分钟`、`开始练习`、`查看全部`、`今日`、`岗位`、`进度`、`备考`、`我的`。

真实登录用户的姓名、岗位、数量和薪资由 API 替换示例值；这属于数据替换，不得改变版式层级或组件结构。

## 核心交互

1. 注册或登录后，未完成画像的用户首先看到“完善求职画像”。
2. 保存画像后刷新个性匹配，推荐列表展示匹配点、缺口与薪资适配，不复用旧系统的单一全局画像结论。
3. 用户可收藏、忽略或更新岗位阶段；状态只属于当前用户。
4. 进入备考可完成每日题单、提交答案、查看解析并累积个人进度。
5. 套餐页显示 Free/Pro/Coach 权益和实际服务状态；支付未配置时只能进入候补/说明状态，不能显示虚假成功。

## 设计对照中的已知实现边界

- 概念图中的公司图标只表示头像占位规则。产品实现使用安全的公司首字母/品牌色块，除非仓库拥有明确授权的品牌资产。
- 桌面和移动概念中的岗位、薪资与数量是布局样例；浏览真实目录时由 API 数据替换。
- PWA 覆盖桌面和手机浏览器并可安装，但不等于已经完成 App Store/Google Play 上架。
