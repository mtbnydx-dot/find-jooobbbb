# 题库内容与入库规则

## 当前实际内容

- 保留原 12 条求职/专业路径、72 道原创题及既有答题历史。
- 新增行测专项免费体验路径：120 道原创模拟题。言语理解、数量关系、判断推理、资料分析各 30 道；均为可作答的单选题，附答案和解析。
- 政治理论、常识判断目前各 0 道；没有通过核验的内容不凑数。
- 行测原创题并非历年真题、官方样题或完整考试等比例模拟卷。资料分析数字全部明确标记为虚构练习资料，不作为现实统计。
- 官方大纲与例题链接只是外部参考资料，不计入可答题量，也不等于取得转载或商用许可。
- 免费行测路径为额外赠送，不替换原有两条免费路径；答题与其他路径共用套餐的每日次数。

## 内容类别和使用权限是两回事

内容类别 `contentKind`：

| 值 | 含义 |
| --- | --- |
| `original_mock` | 原创模拟；不能用年份、企业名称包装成真题 |
| `official_sample` | 官方发布的样题，不能称完整历年试卷 |
| `past_paper` | 能核验考试、年份、原卷题号的历年真题 |

使用权限 `sourceType`：`original`、`authorized`、`unverified`。
原题出自何处与是否有权在本平台使用必须分别核验。购买书籍、公开网页、网盘共享、回忆版或某代码库有开源协议，均不能单独证明内含所有试题的再发行权。

外部样题和历年真题发布前必须有原始标题、原始链接、年份、题号、核验记录、授权来源、署名/许可说明及使用权确认；缺少信息只能留草稿。
管理员填写这些信息是工作流门槛，不等于系统能独立验证其真实性，仍需要内容审核人员核对实际材料。
已有历史试卷保留当时快照，旧快照没有来源时显示未记录，不借用后来修改的来源证明。

## 批量导入

入口：后台内容管理 → 批量导入。可上传 UTF-8 JSON 文件或粘贴 JSON 数组，每批最多 200 条。

1. 先预览：逐行显示可导入、重复、答案冲突、格式错误。
2. 同题干、同选项（忽略选项顺序/空白/大小写）视为同题，跨批次及草稿/发布版本检查。
3. 相同题目却有不同答案时阻断整批，不能自动覆盖；任何格式错误也阻断整批。
4. 人工确认后只生成草稿，重复条目跳过。提交时服务端再次核验，写入失败整批回滚。
5. 每题补齐来源和使用权限，再逐题审核发布；不自动发布外部材料。

接口：`POST /api/v1/admin/content/import`，仅管理员/内容编辑可用。
请求 `{ "records": [题目对象], "dryRun": true }`；缺省也仅预览，明确 `false` 才导入草稿。
预览结果不可作为发布凭据。该接口不抓取外部链接，不登录第三方题库，不绕过付费或访问限制。

题目对象字段：`trackId`、`type`、`difficulty`、`prompt`、`options`、`answer`、`explanation`、`contentKind`、`examType`、`section`、`year`、`region`、`questionNumber`、`sourceTitle`、`sourcePublisher`、`sourceUrl`、`sourceEvidence`、`sourceType`、`author`、`licenseNote`、`rightsConfirmed`。

行测使用 `trackId: track_xingce`、`examType: xingce`；板块为 `political_theory`、`general_knowledge`、`verbal`、`quantitative`、`reasoning`、`data_analysis`。
单选答案应填写选项的完整文字，不填 A/B/C/D；多选为选项文字数组。
来源证明只对后台编辑显示，不向学生泄露内部授权文件或记录。

## 后续扩充的质量门槛

优先获得可在本产品中使用的正式题源/授权材料，再扩充真题；原创模拟作为明确标注的补充，不承诺“全网真题”或“全专业考试全覆盖”。
审题检查题意唯一、答案正确、解析可复核、单位和统计口径一致；数字类题目有独立算式回归。版本更新不能改掉用户已做试卷的历史答案。
图形推理、带图表试题及政治时效题需要额外图文呈现/事实审核，当前首批文字题不宣称覆盖这些能力。

官方范围参考（2026-10-23 核验）：[2026 年国考大纲官方转载](https://www.forestry.gov.cn/c/www/gsgg/645383.jhtml)、[事业单位公开招聘分类考试大纲官方发布页](https://rst.hunan.gov.cn/rst/hnrsksw/c103117/c103119/202606/t20260608_33995613.html)。更新的 2027 年国考大纲链接由 `server/product/exam-sources.js` 统一维护。
