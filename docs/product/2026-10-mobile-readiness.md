# 手机端后端与产品完善（2026-10-23）

## 本次边界

沿用 `codex/job-platform-memberships`，保留旧工作台、采集服务和 `/exam`。只在本机验证通过后切换正式 `/app` 与预览 `/usertest`。不启用定时备份，不覆盖个人画像、收藏、订阅和历史答题记录。

## 已实现的代码

- 岗位：按中国截止日（含当天）默认隐藏明确过期信息；未知/滚动日期保留并标注。用户历史收藏不删除。版本绑定分页避免更新期间静默漏页。来源补全仅映射明确薪资/要求字段；后台更正必须有公开依据，并留审计。
- 手机接口：Cookie 与 Bearer 并行；设备信息、会话轮换、邮箱一次性链接、结构化错误、明确跨域白名单。练习请求幂等，画像/试卷乐观版本校验，交卷结果冻结并可重新读取。
- 手机页面：保存请求串行、冲突选择、本机草稿、切后台墙钟计时、网络故障与登录失效分开、刷新解析与重做状态修复。
- 个人 AI：仅在用户明确同意后发送本人的精简画像及岗位事实；与旧版全局 AI 分离，持久任务、分批执行、缓存、用量和每日额度、取消/重试、后台配置与概览。
- 通知：后台生成截止/跟进/学习/保存搜索提醒；outbox、偏好、已验证邮箱、推送设备归属、有限重试与渠道状态。
- 商业：交易账本与可删除的账号业务记录分离，支付 provider 和验签事件契约、幂等发放权益、退款事实登记及权益处理，不把登记当实际打款。
- 附件：本人专属 TXT/PDF/DOC/DOCX 存储、去重、预览状态、下载、删除、配额；只有 UTF-8 TXT 直接提取文本。
- 后台：来源质量、当前用户行为覆盖、从本版本开始的每日使用类别、会员交易与 AI Token 统计。没有真实单价时不编造成本。

## 外部条件与不能宣传的能力

- 用户暂无支付、邮件和推送服务账号；此次完成适配能力，渠道保持未配置。不等于微信/支付宝扣款、短信、邮件或系统推送已验收。
- 现有原始岗位来源没有薪资字段，映射和审核功能不能产生真实缺失数据，需要持续引入含薪资的来源或核验补充。
- 题库继续使用真实来源分类和授权发布门禁；现有 192 道题中 120 道为行测原创模拟。没有获得可收录真题文件，不编造“海量真题”。
- PDF/Word 仅存储下载，未实现 OCR / 全文解析 / AI 简历改写；当前已有结构化求职画像和 TXT 提取。
- PWA 只缓存外壳，不缓存私人 API 或参考答案；已打开页面的本机草稿不等于可离线冷启动完整刷题。
- 本次不包含原生 App 包、App Store / 国内安卓商店 / Google Play 上架，也不代替实体 iPhone、Android 真机验收。

## 验证与发布门槛

1. 单元/接口回归覆盖移动冲突、幂等、任务隔离、通知、交易、附件和既有功能。
2. 浏览器验证桌面及手机视口、弱网、后台/恢复、PWA、后台入口；截图及测试脚本放 `E:/job-sync-qa-20261023/mobile-readiness`，不放业务数据或密钥。
3. 13,038 条合成岗位 / 8 个画像本机性能冒烟：冷匹配 p50 178 ms / p95 309 ms，缓存命中 p50 1 ms / p95 4 ms；缓存限制 50,000 条结果。这不是生产并发承诺。
4. 发布使用新的 release，数据库在线快照、独立 canary（禁用 worker）、先预览后正式、公网回归、旧进程与原记录完整性核对；只读监测确认备份 timer 仍为 disabled/inactive。

本机验收记录：185 项自动化回归通过；使用独立虚构画像与单条合成岗位调用现有 DeepSeek 服务，任务完成、返回 1 条推荐，实际计量 588 Token。桌面 1440px / 手机 390px 浏览器检查覆盖串行保存、跨设备冲突、重复提交、刷新解析、断网恢复、PWA 外壳和超时；这不等于实体手机或原生 SDK 认证。

发布收尾约束：收到停服信号后立即停止领取个人 AI/通知任务，与旧采集任务并行收尾；产品服务显式保留 180 秒停止时间。AI 的已发出请求不能撤回，费用按已获得的服务返回计量，异常中断仍可能存在上游已收费但本地未收到回执的窗口。

接口详见 [mobile-api.md](mobile-api.md)，外部能力详见 [integrations.md](integrations.md)。
