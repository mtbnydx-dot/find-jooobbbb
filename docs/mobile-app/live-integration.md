# 手机端真实接入与发布说明

## 业务边界

手机端为同源移动 Web/PWA，不是 APK/IPA。正式路径 `/app/mobile/index.html#/discover` 使用 `/api/v1`，测试路径 `/usertest/mobile/index.html#/discover` 使用 `/usertest/api/v1`；不跨环境混用 Cookie 或资料。主站“我的”及账户菜单提供入口，旧原型入口转至对应测试手机端。

- 登录、注册、画像、会话与账号设置共用现有服务。密码不进入本机存储；401 会话失效和临时网络失败分别处理。修改密码时输错当前密码不误退出有效会话。前台身份核验与登录/退出分别管理，核验期间暂时禁止交互；同一账户保留表单，不同账户重新建立页面并清理旧考试草稿，保存搜索与练习结果的页面状态绑定本人。
- 真实岗位搜索、条件筛选、分页、保存搜索和原公告证据。只修改收藏字段不会覆盖投递阶段或私人备注；打开外部投递链接不自动标记已投递。多来源规范岗位 ID 和原公告核验语义沿用后端。
- 投递阶段、下一步、跟进时间保存在本人云端账户。进度是用户自行维护，并非招聘单位回执。
- 真实已发布题库、逐题题源、规则评分、分科分页练习、错题和题目收藏。新增 `/me/prep/bookmarks`、`/me/prep/wrong` 和 `/me/prep/questions/:id` 接口，强制本人权限及当前套餐限制。错题为普通练习与考试中最近一次得分未满分的题；复习满分后移出当前错题，历史作答仍保留。
- 考试保存串行提交并携带 `expectedVersion`，刷新恢复云端记录；冲突需明确选择。失去响应后可核对、重试，交卷不会重复计分。计时展示建议用时和实际已用时，不声称服务器强制考试限时。
- 会员显示服务器实际套餐、价格、周期、权益与用量。只提交人工审核申请、查看记录或撤回，后台审核生效后手机和网页可读取同一权益。未接入在线支付，不自动收款、不自动续费、不包含原生 IAP。
- 简历附件实际上传/下载/删除，TXT 文本预览沿用服务能力；PDF/Word 不伪称自动解析。站内消息、渠道状态、工单与保存搜索为真实数据；邮件或推送未配置时明确提示，不模拟送达。
- 个人 AI 只在用户明确同意后创建真实任务；打开页面、登录和保存画像不会自动消耗模型额度。本轮验收不使用生产付费模型。

## 手机与存储

采用触控目标、16px 表单字体、长文本换行、滚动表单、受控焦点面板及安全区域留白；兼容不支持动态视口单位的浏览器回退。可通过浏览器添加至主屏幕；系统安装入口取决于具体浏览器。

独立 service worker 只缓存本手机端静态页面、样式、脚本和图标，不缓存 API、私人记录、参考答案或完整题库。主站 worker 排除手机路径，避免互相覆盖缓存。离线仅能打开页面外壳和当前标签页个人考试草稿，不能假提交；新登录、岗位读取、刷题、交卷等需要网络。草稿按账户和考试隔离，主动退出或登录失效时清理。

Android Chrome 与 iOS Safari 应分别进行真机测试：键盘遮挡、旋转、安全区域、文件选择/下载、主屏幕启动与系统返回、后台切换恢复。Playwright Chromium/WebKit 是浏览器内核与视口验收，不是实际 Android/iPhone 真机或应用商店验收。当前无原生系统推送、应用商店内购、深链接唤起和离线题库。

## 开发与构建

目录仍保留为 `web/mobile-design` 以便追踪原型升级历史；运行代码不再加载 `src/demo`。

本机 API 默认为 `http://127.0.0.1:3320`，Vite 手机端默认为 `http://127.0.0.1:4185/mobile-design/index.html#/discover`。可用 `MOBILE_API_TARGET`、`MOBILE_API_BASE` 覆盖，但不得将测试写入生产。

常规 `web/` 的 `npm run build` 现在同时构建主站、`mobile/` 客户端和旧入口跳转，再注入主站缓存清单。发布到临时输出目录时，按顺序执行主站 Vite 构建、`node scripts/build-mobile.mjs <output>`、`node scripts/inject-sw-assets.mjs <output>`。整个过程中保持同一 `PRODUCT_PUBLIC_BASE`、`OPS_PUBLIC_BASE`；手机 API 路径自动由其推导。

发布流程仍为本机测试 → 隔离 canary → 测试站 → 正式站 → 公网页面验收。部署不得重置数据库、用户画像、自选、会员或题库。只增加带外键级联的题目收藏表，无旧数据批量重写；收藏纳入账号导出与注销。定时备份保持禁用。
